# Discovering the Higgs boson: computational project (Year 3)

Numerical methods written from scratch in Python to estimate the significance of a Higgs-like signal over background: numerical integration (`Integration.py`), differentiation (`Differentiation.py`), maximisation of the significance over the mass window (`Maximisation.py`) and the analysis (`Analysis.py`). Imperial College London, 2024.

## Run
Run any module directly (e.g. `python Analysis.py`); results are printed or plotted.
